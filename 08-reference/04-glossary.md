# Quick glossary

[Course home](../README.md) · [All lessons](../COURSE.md) · [Section index](README.md) · [← Previous](03-continuing-the-course.md) · [Next →](05-source-and-coverage.md)

| Term | Working definition |
|---|---|
| Alpha | Return contribution beyond the chosen explanatory benchmark/model; not simply a rising price |
| Bar / OHLCV | Open, high, low, close, and volume aggregated over an interval |
| Bid / ask | Displayed buying / selling interest at a price |
| Spread | Ask minus bid at a particular observation |
| Basis point | 0.01 percentage point; 100 basis points equal 1% |
| Signal | Information used to choose exposure |
| Target position | Desired inventory after considering the signal and policy |
| Order | Request to execute under specified conditions |
| Fill | Actual execution of some quantity |
| Position | Inventory attributed under the configured OMS |
| OMS | Order management system |
| Netting | Combine opposing trades into net inventory within the applicable scope |
| Hedging | Maintain distinct internal positions where supported |
| Notional | Quantity multiplied by price and any applicable contract multiplier |
| Mark | Price used to value holdings; not necessarily an executable liquidation price |
| Realized PnL | Profit or loss attributed to closed quantity under the accounting convention |
| Unrealized PnL | Marked gain or loss on still-open holdings |
| Drawdown | Decline from a previous equity peak |
| Turnover | Trading activity relative to capital under a stated calculation convention |
| Slippage | Execution difference from a specified reference price |
| Market impact | Price/liquidity change caused by your own trading |
| Point-in-time data | Values and membership reflecting information available at the historical decision time |
| Reconciliation | Comparing and resolving local and external trading state |
| Warm-up | Earlier observations needed before an indicator or model is ready |
| Adapter | Integration translating between Nautilus and an external provider or venue |
| Kill switch | A specified emergency control with separately defined entry, order, and inventory actions |
