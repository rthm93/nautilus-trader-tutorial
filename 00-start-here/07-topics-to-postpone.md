# Topics to postpone

[Course home](../README.md) · [All lessons](../COURSE.md) · [Section index](README.md) · [← Previous](06-development-roadmap.md) · [Next →](../01-foundations/01-event-driven-trading.md)

You will eventually encounter these, but learning them now will create more confusion than benefit:

- L2/L3 order-book strategies
- market making
- multi-venue arbitrage
- execution algorithms
- options
- futures
- margin/leverage
- short selling
- portfolio optimization
- machine learning
- reinforcement learning
- alternative data
- custom adapters
- Rust strategy implementation
- high-frequency trading

Nothing is wrong with those topics.

You just don't yet have the foundation that makes them useful.
