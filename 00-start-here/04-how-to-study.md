# How to study this course

[Course home](../README.md) · [All lessons](../COURSE.md) · [Section index](README.md) · [← Previous](03-system-map.md) · [Next →](05-learning-sequence.md)

Read Phase A through Phase F in order, using the capstone as a running project. Each numbered lesson has a concrete objective, an exercise, and an answer checkpoint. Explain your answer before reading the checkpoint. Keep an experiment journal containing what you expected, what happened, and what changed your explanation.

The lesson numbers 01–50 follow the original table of contents. Lettered companion lessons retain useful material that the original numbered modules covered separately. Original module numbers are mapped in the reference section; they are not the new lesson numbers.

Start with concepts and hand calculations, then implement the capstone stages. A lesson being read does not mean its implementation gate has passed. Keep your own progress notes without marking exercises as completed until you have evidence.

Code fragments inherited from the outline are **conceptual sketches**, not runnable programs. They omit configuration, imports, credentials, data, and failure handling. This repository is a Markdown course, not an implemented or validated trading bot. The capstone specifies the work needed to build one.

Before copying any API call, record your Python and NautilusTrader versions and use matching documentation. The `latest` documentation can change; class names and configuration fields in an older tutorial may differ. Never combine incompatible examples without checking their version.

Begin with one liquid equity or ETF, a cash account, long-only exposure, and a fixed allocation. Dollar examples are arithmetic illustrations; they do not select a broker, market, currency, or investment for you.
