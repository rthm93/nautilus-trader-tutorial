# Recommended learning sequence

[Course home](../README.md) · [All lessons](../COURSE.md) · [Section index](README.md) · [← Previous](04-how-to-study.md) · [Next →](06-development-roadmap.md)

Spend your first pass in this order:

| Stage | Learn | Build |
|---|---|---|
| 1 | Events, Strategy lifecycle, instruments | Log bars |
| 2 | Indicators and signals | MA crossover |
| 3 | Orders and fills | Submit one market order |
| 4 | Positions and Portfolio | Enter/exit correctly |
| 5 | BacktestNode | Full backtest |
| 6 | Data Catalog | Persistent historical dataset |
| 7 | Execution simulation | Slippage/cost scenarios |
| 8 | Risk | Position sizing + limits |
| 9 | Research methodology | Out-of-sample tests |
| 10 | Equity details | Corporate-action-safe data |
| 11 | Sandbox | Real-time paper trading |
| 12 | Operations | Logs/recovery/reconciliation |
| 13 | Live | Tiny real position |
| 14 | Scaling | Only after sustained validation |
